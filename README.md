# AI-SHOPPING-AGENTS-THESIS
Bachelor's thesis: consumer trust in AI shopping agents (TAM, MLR, Random Forest, K-means) in Python.

## Objective
What drives consumers to trust AI shopping agents with purchases.

## Data
200-respondent survey. 

## Methods
Extended TAM model, Multiple Linear Regression, Random Forest, K-means (Python).

## Key results
- Main drivers of adoption: perceived usefulness, adoption and trust.
- 3 consumer segments identified: Enthusiasts, pragmatists and sceptics.
